# Student Academic Performance Analysis

## Project Overview

This project focuses on exploring student academic performance using Python and publicly available data.

The main purpose of the project is to understand how factors such as study hours, attendance, previous academic performance, internet access and extracurricular activities are related to students' final academic performance.

The project begins with exploratory data analysis before considering any machine learning approach.

## Objectives

- Understand the structure and quality of the dataset.
- Identify missing values and duplicate records.
- Perform data cleaning and preparation.
- Analyze important numerical and categorical variables.
- Study relationships between study habits, attendance and academic performance.
- Identify patterns and possible outliers.
- Create meaningful visualizations.
- Evaluate the proposed hypotheses using the available data.

## Research Questions

1. Is study time associated with final academic performance?
2. Is attendance related to final percentage?
3. Does previous academic performance relate to current performance?
4. Does internet access show any relationship with academic performance?
5. Is extracurricular participation associated with student performance?

## Hypotheses

- H1: Study hours are positively associated with final percentage.
- H2: Attendance is positively associated with final percentage.
- H3: Previous-year score is positively associated with final percentage.
- H4: Internet access may be associated with academic performance.
- H5: Extracurricular participation may be associated with academic performance.
